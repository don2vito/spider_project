# HTML晨报自动生成系统 - 产品需求文档

## 概述

- **摘要**：构建一个HTML应用程序，能够读取Excel数据文件，自动计算并生成两张格式化的业务报表
- **用途**：自动化生成每日晨报报表，减少手动计算和整理工作
- **目标用户**：业务分析人员、管理人员

## 目标

- 实现Excel文件导入功能
- 自动识别最新统计日期
- 自动计算表1和表2的所有指标
- 生成与参考样式一致的HTML表格
- 提供友好的用户界面

## 非目标（范围外）

- 不实现数据编辑功能
- 不实现历史数据对比功能
- 不实现图表可视化
- 不实现数据导出到其他格式

## 背景与上下文

目前需要基于"数据整理.xlsx"文件，参考"数据样式.xlsm"、"表1.png"、"表2.png"中的样式以及"需求整理.docx"中的计算规则，创建一个自动化的HTML报表生成工具。

## 功能需求

1. **FR-1**：Excel文件导入功能
   - 支持上传和解析"数据整理.xlsx"文件
   - 读取三个工作表："月数据（每日更新）"、"累计数据（每月更新）"、"目标（每月更新）"

2. **FR-2**：表1生成功能
   - 计算转换率、毛利率等指标
   - 展示当日、月累计、年累计数据
   - 计算目标达成率和目标偏差

3. **FR-3**：表2生成功能
   - 计算月度日均标、当日进度
   - 展示期间利润、期间业绩
   - 计算期间偏差

4. **FR-4**：用户界面
   - 文件上传界面
   - "生成"按钮
   - 结果展示页面

## 非功能需求

1. **NFR-1**：响应式设计
   - 界面在不同设备上都能良好显示

2. **NFR-2**：计算准确性
   - 所有计算结果必须精确

## 约束条件

- **技术**：使用纯前端技术（HTML/CSS/JavaScript）
- **外部依赖**：需要使用SheetJS库解析Excel文件
- **样式**：需与参考图片和Excel文件中的样式保持一致

## 假设条件

- Excel文件结构保持不变
- 数据格式保持一致
- 所有计算规则保持不变

## 验收标准

### AC-1：Excel文件导入功能

- **给定**：用户已准备好"数据整理.xlsx"文件
- **当**：用户上传该文件并点击"生成"按钮
- **则**：系统成功解析文件并读取所有工作表数据
- **验证类型**：程序化验证

### AC-2：表1正确生成

- **给定**：Excel文件已成功导入
- **当**：系统生成表1
- **则**：所有计算指标正确（转换率、毛利率、达成率等），格式与参考一致
- **验证类型**：人工验证 + 程序化验证

### AC-3：表2正确生成

- **给定**：Excel文件已成功导入
- **当**：系统生成表2
- **则**：所有计算指标正确（月度日均标、当日进度、期间偏差等），格式与参考一致
- **验证类型**：人工验证 + 程序化验证

### AC-4：自动识别统计日期

- **给定**：Excel文件包含多天数据
- **当**：系统解析数据
- **则**：自动识别有数据的最新日期作为统计日期
- **验证类型**：程序化验证
