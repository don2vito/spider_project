## 2. 产品概述

### 2.1 产品背景
企业内部需要每日生成晨报报表，用于展示前一日各销售渠道的核心业绩指标。传统方式依赖手工整理Excel数据并制作报表，效率低下且容易出错。本产品旨在通过自动化的HTML应用，实现数据导入、自动计算、报表生成和导出的一体化流程。

### 2.2 产品目标
- 实现Excel数据的一键导入和自动解析
- 自动生成两张标准报表（主要指标 + 业绩复盘）
- 支持多格式导出（Excel、JPG 300PPI、PDF）
- 提供日期切换功能，支持历史数据回溯
- 支持责任人信息展示，支持换行显示

### 2.3 目标用户
企业内部数据分析人员、管理层、运营团队

## 3. 功能需求

### 3.1 数据导入模块

#### 3.1.1 Excel文件上传
- **功能描述**：用户通过点击上传区域或拖拽方式上传 `.xlsx` 格式的数据文件
- **支持格式**：`.xlsx`（Microsoft Excel 2007+）
- **文件要求**：
  - 必须包含三个指定工作表：
    - `月数据（每日更新）`：每日各渠道的交易数据
    - `累计数据（每月更新）`：历史累计数据
    - `目标（每月更新）`：各渠道的月度目标数据
- **交互细节**：
  - 上传区域支持点击和拖拽两种操作
  - 拖拽时区域边框变色提示
  - 上传成功后显示文件名
  - 文件格式错误时弹出提示

#### 3.1.2 示例数据加载
- **功能描述**：提供示例数据供用户快速体验功能
- **触发方式**：点击"加载示例数据"按钮
- **数据来源**：`data/data.xlsx`

### 3.2 报表生成模块

#### 3.2.1 自动识别统计日
- **功能描述**：系统自动识别数据文件中最新有数据的日期作为默认统计日
- **识别逻辑**：遍历 `月数据（每日更新）` 表，查找 `订购额`、`销售额`、`利润额` 任一字段大于0的最大日期

#### 3.2.2 日期切换
- **功能描述**：用户可通过下拉选择器切换不同的统计日期
- **可选范围**：数据文件中所有有数据的日期，按降序排列
- **联动效果**：切换日期后，两张报表自动重新计算和渲染

### 3.3 表1 - 主要指标

#### 3.3.1 数据维度
| 维度 | 说明 |
|------|------|
| 当日 | 统计日当天的数据 |
| 月累计 | 统计日所在月份1日至统计日的累计数据 |
| 年累计 | 当年1月1日至统计日的累计数据（含历史累计） |

#### 3.3.2 渠道结构

**东方购物 - 电视端及APP（红色表头）**
- 数据来源：`P1` + `金条还原`
- 指标：转换率、毛利率、订购额、销售额、销售利润
- 转换率 = 销售额 / 订购额
- 毛利率 = 销售利润 × 1.13 / 销售额
- 毛利率行不加粗显示

**定制类（黄色表头）**
- 指标：订购额

**私域第三方（黄色表头）**
- 指标：订购额

**自营供应链（深蓝色表头）**
- 指标：销售额
- 渠道名称单元格留空不显示文字

**白玉兰直播间（深蓝色表头）**
- 指标：GMV（订购额）
- 渠道名称单元格留空不显示文字

#### 3.3.3 目标计算逻辑

| 目标类型 | 计算方式 | 使用目标类型 |
|---------|---------|------------|
| 日目标 | 当月目标 / 当月天数 | 滚动目标（电视及APP）/ 年初目标（其他） |
| 月累计目标 | 当月目标 / 当月天数 × 统计日 | 滚动目标（电视及APP）/ 年初目标（其他） |
| 年累计目标 | 之前月份目标累计 + 当月目标按比例 | 年初目标 |

#### 3.3.4 达成率与偏差
- 达成率 = 实际值 / 目标值，格式为 `0%`
- 目标偏差 = 实际值 - 目标值，格式为 `↑ 1.2` 或 `↓ 1.2`（万元）
- 达成率颜色：≥100% 红色，≥80% 橙色，<80% 绿色
- 偏差颜色：正数绿色，负数红色

#### 3.3.5 全公司汇总
- 全公司GMV = 电视端及APP订购额 + 定制类订购额 + 私域第三方订购额 + 白玉兰直播间订购额
- 全公司销售利润 = 电视端及APP销售利润 + 私域第三方销售利润

### 3.4 表2 - 业绩复盘

#### 3.4.1 销售利润部分

| 渠道 | 计算方式 | 目标来源 | 责任人 | 加粗 |
|------|---------|---------|--------|------|
| 东方购物 | P1 + 私域第三方 | 电视及APP滚动目标利润额 | （空白） | 是 |
| 电视商品 | 直接取数 | 电视商品滚动目标利润额 | 张凌云<br>(温佳敏) | 否（缩进） |
| 电商商品 | 直接取数 | 电商商品滚动目标利润额 | 张凌云 | 否（缩进） |
| 仅电视端及APP | P1 - 私域东购部分 - 数据库营销 | 仅电视端及APP滚动目标利润额 | 曹俊<br>(温佳敏) | 否 |
| 数据库营销 | 直接取数 | 数据库营销滚动目标利润额 | 赵鹤/王涛 | 否（缩进） |
| 私域 | 私域东购部分 + 私域第三方 | 私域滚动目标利润额 | 张音祺 | 否 |

#### 3.4.2 销售/GMV部分

| 渠道 | 指标 | 目标来源 | 责任人 |
|------|------|---------|--------|
| 自营供应链 | 销售额 | 自营供应链年初目标销售额 | 许震威 |
| 白玉兰直播间 | GMV（订购额） | 白玉兰直播间年初目标订购额 | 许震威 |

#### 3.4.3 计算逻辑
- 月度日均标 = 当月目标 / 当月天数
- 当日进度 = 当日实际值 / 月度日均标
- 期间目标 = 当月目标 / 当月天数 × 统计日天数
- 期间偏差 = 期间实际值 - 期间目标

#### 3.4.4 责任人显示规则
- 责任人信息写死在代码中
- 支持 `\n` 换行符转 `<br>` 标签显示
- 空白责任人显示为 `-`

### 3.5 导出功能

#### 3.5.1 导出Excel
- 将两张报表分别导出为Excel工作表
- 文件名格式：`晨报_YYYYMMDD.xlsx`

#### 3.5.2 导出JPG（300PPI）
- 将报表内容渲染为高清图片
- 分辨率：300 PPI（像素每英寸）
- 目标宽度：2480px（对应A4纸210mm宽度）
- 图片质量：JPEG，质量系数0.95
- 文件名格式：`晨报_YYYYMMDD.jpg`

#### 3.5.3 导出PDF
- 将报表内容转换为PDF文档
- 页面尺寸：A4
- 支持多页自动分页
- 文件名格式：`晨报_YYYYMMDD.pdf`

## 4. 数据需求

### 4.1 Excel数据结构

#### 4.1.1 月数据（每日更新）
| 字段 | 类型 | 说明 |
|------|------|------|
| 日期 | Date | Excel日期格式 |
| 渠道 | String | 渠道名称 |
| 订购额 | Number | 当日订购金额 |
| 销售额 | Number | 当日销售金额 |
| 利润额 | Number | 当日利润金额 |

**渠道枚举值**：P1、金条还原、定制类、私域第三方、白玉兰直播间、自营供应链、电视商品、电商商品、数据库营销、私域东购部分

#### 4.1.2 累计数据（每月更新）
| 字段 | 类型 | 说明 |
|------|------|------|
| 渠道 | String | 渠道名称 |
| 指标 | String | 指标类型（订购额/销售额/利润额） |
| 数值 | Number | 累计数值 |

#### 4.1.3 目标（每月更新）
| 字段 | 类型 | 说明 |
|------|------|------|
| 月份 | Number | 1-12 |
| 订购额目标 | Number | 当月订购额目标 |
| 销售额目标 | Number | 当月销售额目标 |
| 利润额目标 | Number | 当月利润额目标 |
| 渠道 | String | 渠道名称 |
| 归属 | String | 目标类型（滚动目标/年初目标） |

### 4.2 数据计算规则

#### 4.2.1 年累计计算
```
年累计 = 历史累计（累计数据表）+ 当年1月1日至统计日的月数据累计
```

#### 4.2.2 电视端及APP计算
```
电视端及APP = P1 + 金条还原
```

#### 4.2.3 欧洲数字格式解析
支持自动识别逗号和点作为小数点/千分位分隔符：
- `1.234,56` → 1234.56（逗号作为小数点）
- `1,234.56` → 1234.56（点作为小数点）

## 5. 非功能需求

### 5.1 性能需求
- 数据导入和解析时间 < 3秒（文件大小 < 5MB）
- 报表渲染时间 < 1秒
- 导出JPG时间 < 5秒

### 5.2 兼容性需求
- 浏览器：Chrome 90+、Edge 90+、Firefox 88+
- 不支持IE浏览器

### 5.3 安全需求
- 所有数据处理在客户端完成，不上传至服务器
- 不存储用户上传的文件数据
