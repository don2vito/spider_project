# HTML晨报生成器 - UI设计文档

## 1. 设计概述

### 1.1 设计目标
- 打造专业、清晰的企业级数据报表界面
- 确保数据的可读性和对比性
- 通过色彩区分不同业务板块
- 支持打印和导出场景的高保真呈现

### 1.2 设计原则
- **清晰优先**：数据表格是核心，所有设计服务于数据的可读性
- **色彩语义化**：不同颜色代表不同业务板块，形成视觉记忆
- **响应式适配**：适配不同屏幕尺寸，确保核心功能可用
- **导出友好**：打印和导出时保持样式一致性

## 6. 交互设计

### 6.1 页面流程

```
[上传页面]
    │
    ├─ 点击/拖拽上传文件 ──→ 显示文件名 ──→ 点击"生成报表"
    │                           │
    └─ 点击"加载示例数据" ───────┘
                                  │
                                  ▼
                         [报表页面]
                                  │
                    ┌─────────────┼─────────────┐
                    ▼             ▼             ▼
              [切换日期]    [导出Excel]    [导出JPG/PDF]
                    │             │             │
                    └─────────────┴─────────────┘
                                  │
                                  ▼
                           [返回上传页]
```

### 6.2 状态反馈

| 操作 | 反馈方式 |
|------|---------|
| 文件上传成功 | 显示文件名，展示"生成报表"按钮 |
| 文件格式错误 | alert弹窗提示 |
| 数据加载中 | 全屏遮罩 + 旋转动画 |
| 导出进行中 | 全屏遮罩 + 旋转动画 |
| 导出完成 | 浏览器自动下载文件 |
| 导出失败 | alert弹窗提示错误信息 |

### 6.3 悬停效果

| 元素 | 悬停效果 |
|------|---------|
| 上传区域 | 边框变红，背景变浅红 |
| 主要按钮 | 背景色变深红 |
| 表格行 | 无（保持数据清晰） |

## 9. 导出样式规范

### 9.1 JPG导出（300PPI）
- 背景色强制为 #ffffff
- 保持所有CSS样式
- 分辨率：2480px宽（A4@300PPI）
- 格式：JPEG，质量95%

### 9.2 PDF导出
- 页面尺寸：A4（210mm × 297mm）
- 内容缩放自适应页面宽度
- 支持多页自动分页

### 9.3 Excel导出
- 保留表格结构和数据
- 不保留颜色样式（Excel原生限制）
