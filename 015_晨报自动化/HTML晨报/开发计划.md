# HTML报表应用开发计划

## 项目概述
根据《数据整理.xlsx》中的数据，参考《表1.png》和《表2.png》的红色主题样式，开发一个完整的HTML报表应用，支持日期切换、数据筛选和导出功能。

## 当前状态分析

### 数据源分析
1. **数据整理.xlsx** 包含3个工作表：
   - `月数据（每日更新）`：每日各渠道数据（订购额、销售额、利润额）
   - `累计数据（每月更新）`：年度累计数据
   - `目标（每月更新）`：各渠道月度/年度目标

2. **渠道分类**：
   - 电视及APP（P1）
   - 金条还原
   - 定制类
   - 私域第三方
   - 白玉兰直播间
   - 自营供应链
   - 电视商品、电商商品、数据库营销、私域东购部分

### 参考样式分析
- **表1（主要指标）**：红色主题，包含达成率、目标偏差等指标
- **表2（业绩复盘）**：红色主题，包含当日进度、期间偏差等指标

## 功能需求

### 核心功能
1. **数据导入**：上传Excel文件并解析
2. **日期选择**：选择统计日期（自动识别最大有数据日期）
3. **表格生成**：自动生成表1和表2
4. **数据导出**：支持导出为Excel/PDF

### 计算逻辑

#### 表1 - 主要指标计算
1. **转换率** = 销售额 / 订购额
2. **毛利率** = 销售利润 × 1.13 / 销售额
3. **电视端及APP** = P1 + 金条还原
4. **全公司GMV** = 电视端及APP订购额 + 定制类订购额 + 私域第三方订购额
5. **全公司销售利润** = 电视端及APP销售利润 + 私域第三方销售利润
6. **日目标** = 当月目标 / 当月天数
7. **月目标** = 当月截止到统计日的目标
8. **年累计目标** = 之前月份目标 + 当月截止到统计日的目标
9. **目标达成率** = 实际值 / 目标
10. **目标偏差** = 实际值 - 目标

#### 表2 - 业绩复盘计算
1. **东方购物** = P1 + 私域第三方
2. **仅电视端及APP** = P1 - 私域东购部分 - 数据库营销
3. **私域** = 私域东购部分 + 私域第三方
4. **月度日均标** = 当月目标 / 当月天数
5. **当日进度** = 当日实际值 / 月度日均标
6. **期间目标** = 当月目标 / 当月天数 × 统计日天数
7. **期间偏差** = 期间利润/业绩 - 期间目标

## 技术架构

### 前端技术栈
- **HTML5** + **CSS3**：页面结构和样式
- **JavaScript (ES6+)**：交互逻辑
- **SheetJS (xlsx.js)**：Excel文件解析
- **Chart.js**（可选）：数据可视化
- **html2canvas + jsPDF**：PDF导出功能

## 样式设计

### 色彩方案（参考表1.png和表2.png）
- **主色调**：红色 (#C00000, #FF0000)
- **背景色**：深红色表头 (#C00000)
- **文字颜色**：白色（表头）、黑色（数据）
- **强调色**：黄色/金色用于特殊标记
- **边框**：细线分隔

### 表格样式
- 表头使用红色背景+白色文字
- 数据行使用斑马纹或白色背景
- 达成率使用百分比格式
- 偏差值使用箭头图标（↑↓）
