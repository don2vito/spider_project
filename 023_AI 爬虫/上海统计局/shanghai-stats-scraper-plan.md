# 上海市统计局数据抓取工具 — 实施计划

## 摘要

为上海市统计局官网 `https://tjj.sh.gov.cn/sjfb/index.html` 构建一套完整的数据抓取与展示工具。包含：
1. **Python Flask 代理服务器** (`server.py`) — 负责抓取网站 HTML、解析数据、代理下载
2. **单页 HTML 前端应用** (`index.html`) — 提供年份/指标选择、数据矩阵展示、详情查看、Excel 下载功能

---

## 一、当前状态分析

### 1.1 网站结构研究结论

| 维度 | 结论 |
|------|------|
| **数据加载方式** | 纯静态 HTML 渲染，**无 Ajax/JSON API** |
| **年份切换机制** | 不同年份对应不同的静态 HTML 页面（`sjfb/index.html`、`sjfb/index_2.html` 等） |
| **数据组织形式** | 矩阵表格：行=指标分类，列=月份(1-12月)，单元格=详情页链接 |
| **详情页内容** | 标题 + 发布日期 + 嵌入图片(表格截图) + 可下载 .xlsx 附件 |
| **子索引页** | 每个指标有独立索引页（如 `ydsj31/index.html`），含分页，列出所有历史数据 |
| **反爬机制** | 较弱（政府网站），但仍需设置合理请求间隔 |

## 三、后端 API 设计（server.py）

### 3.1 端点清单

| 端点 | 方法 | 参数 | 说明 |
|------|------|------|------|
| `/api/years` | GET | 无 | 获取可用年份列表 |
| `/api/matrix` | GET | `year` | 获取指定年份的指标矩阵 |
| `/api/indicator-list` | GET | `indicator_id`, `year` | 获取指定指标的详情列表（含分页遍历） |
| `/api/detail` | GET | `url` | 获取单个详情页信息（标题、日期、xlsx链接） |
| `/api/download-xlsx` | GET | `url`, `filename` | 代理下载 xlsx 文件 |
| `/api/proxy-image` | GET | `url` | 代理转发图片（应对 CDN 跨域） |

### 3.2 核心抓取逻辑

#### `/api/years` — 年份列表
- 抓取 `sjfb/index.html` 首页
- 解析年份下拉菜单 `<select>` 中的 `<option>` 元素
- 提取年份值与对应页面 URL 的映射关系

#### `/api/matrix` — 指标矩阵（核心端点）
- 根据 `year` 参数确定要抓取的页面 URL
- 用 BeautifulSoup 解析主表格 `<table>`
- 遍历每一行：
  - 类别标题行（如"三、工业"）：记录当前分类
  - 指标数据行（含 `<a>` 链接）：提取指标名称、URL前缀、各月份数据链接
- 区分有链接的单元格（已发布）和空单元格（未发布）
- 识别季度数据（如"1季度""1-2季度"）vs 月度数据

#### `/api/indicator-list` — 指标详情列表
- 抓取 `https://tjj.sh.gov.cn/{indicator_id}/index.html`
- 解析列表中的所有条目（标题、链接、发布日期）
- 自动遍历分页（`index_2.html`、`index_3.html`...）
- 根据 `year` 参数过滤，按发布日期升序排列

#### `/api/detail` — 详情页解析
- 抓取传入的 URL
- 提取：标题、发布日期
- 查找"下载附件"区域的 `.xlsx` 链接
- 提取嵌入的图片 URL

#### `/api/download-xlsx` — 文件代理下载
- 后端流式下载 xlsx 文件
- 设置 `Content-Disposition: attachment` 响应头
- 流式转发给前端触发浏览器下载

### 3.3 缓存与限速策略

- **内存缓存**：Python 字典缓存已抓取的 HTML，TTL = 10 分钟
- **请求间隔**：每次请求间隔 0.5 秒，避免对目标服务器造成压力
- **User-Agent**：设置合理的浏览器 User-Agent 头

### 4.2 交互流程

**流程 1：年份 + 指标筛选 → 矩阵展示**
1. 用户选择年份和指标（支持"全部"）
2. 点击"查询数据"
3. 前端调用 `GET /api/matrix?year=2026`
4. 渲染矩阵表格，有数据的单元格可点击，空单元格灰色禁用

**流程 2：点击单元格 → 查看详情**
1. 用户点击矩阵中有数据的单元格
2. 前端调用 `GET /api/detail?url=...`
3. 在详情面板展示：标题、日期、图片预览、下载按钮

**流程 3：批量获取全年数据**
1. 选择特定指标 + 年份后查询
2. 自动调用 `GET /api/indicator-list` 获取该指标该年所有数据
3. 按日期升序追加展示
4. 支持勾选后批量下载或导出汇总 Excel

**流程 4：Excel 导出**
- **单文件下载**：通过 `/api/download-xlsx` 代理下载原始 xlsx
- **汇总导出**：使用 SheetJS 在前端生成汇总 Excel（含指标名称、数据期间、发布日期、原始链接）

### 4.3 视觉设计方向

- **主题**：深色背景 + 金色强调色（呼应官网金色标题风格，但更现代化）
- **配色**：主背景 `#0f1117`、卡片 `#1a1d27`、强调色 `#c9a96e`、链接蓝 `#3b82f6`
- **字体**：Noto Serif SC（标题）+ Noto Sans SC（正文）
- **动效**：单元格 hover 上浮、详情面板 slide-down 展开、加载脉冲动画

```
用户选择年份+指标 → 前端 → GET /api/matrix → 后端抓取 sjfb/index.html → 解析表格 → 返回 JSON
                                                                                      ↓
用户点击单元格 → 前端 → GET /api/detail → 后端抓取详情页 → 提取xlsx链接 → 返回 JSON
                                                                                      ↓
用户点击下载 → 前端 → GET /api/download-xlsx → 后端代理下载 → 流式转发 → 浏览器保存文件
```

## 六、边界情况处理

| 场景 | 处理方案 |
|------|---------|
| 年份页面结构差异（不同年份指标不同） | 完全从 HTML 动态解析，不硬编码指标列表 |
| 季度 vs 月度混合显示 | 解析时识别单元格文本，判断是月份还是季度 |
| 空单元格（未发布数据） | 矩阵中灰色禁用显示，不可点击 |
| 图片 CDN 跨域 (`aka.doubaocdn.com`) | 后端增加 `/api/proxy-image` 代理端点 |
| 子索引页分页（如 ydsj51 有 8 页） | 自动遍历所有分页，合并结果 |
| 统计公报无子索引页 | 跳过子索引请求，直接使用矩阵中的链接 |
| 网站请求超时/错误 | 后端捕获异常返回错误 JSON，前端显示友好提示 |
| 批量下载被浏览器拦截 | 逐个触发下载，每个间隔 500ms |

## 九、假设与决策

1. **不使用 Selenium/Playwright**：网站为纯静态 HTML，无需浏览器渲染引擎
2. **不实现用户认证**：工具为本地使用，无需登录功能
3. **xlsx 内容不解析**：直接下载原始 xlsx 文件，不做内容解析和二次加工
4. **汇总导出使用前端 SheetJS**：避免后端依赖 openpyxl，减少复杂度
5. **请求间隔 0.5 秒**：平衡抓取效率和服务器友好性
