# 克劳锐数据报告爬虫系统 - 产品需求文档 (PRD)

## 1. 产品概述

### 1.1 产品背景
克劳锐(topklout.com)是国内领先的权威自媒体价值排行及版权经纪管理第三方数据监测机构。其官网展示大量行业趋势白皮书和数据报告，涵盖MCN、网红、电商、自媒体、汽车、美妆等多个垂直领域，时间跨度从2017年至今，共计186+份报告。

用户需要一个自动化工具来批量抓取这些报告数据，并通过本地应用进行浏览和下载，以便离线使用和研究分析。

### 1.2 产品目标
- 自动化抓取克劳锐官网全量数据报告（186+份）
- 提供可视化的报告浏览和管理界面
- 支持单个、批量、全量PDF下载
- 一键启动，简单易用

### 1.3 目标用户
- 行业研究人员
- 市场营销从业者
- 数据分析师
- 自媒体从业者

## 2. 功能需求

### 2.1 数据抓取模块

#### 2.1.1 三层爬取策略
系统采用三层递进式爬取策略，确保数据获取的可靠性：

**第一层：API接口拦截（首选方案）**
- 使用 Playwright 启动无头浏览器访问目标页面
- 拦截 `https://motion.topklout.com/api/Apidata/web/reportList` 接口响应
- 解析 JSON 格式响应数据
- 提取报告标题、封面图片URL、标签分类

**第二层：HTML DOM解析（备选方案）**
- 当 API 拦截失败时启用
- 使用 Playwright 获取页面完整 HTML
- 使用 BeautifulSoup 解析 `.reports-list .swiper-slide` 元素
- 提取 `.rep-title`（标题）和 `.cover img`（封面图片）

**第三层：Playwright浏览器兜底（最终方案）**
- 当前两层均失败时启用
- 使用 Playwright 控制真实浏览器
- 通过 DOM 操作逐个提取报告数据
- 处理可能的懒加载和动态渲染

#### 2.1.2 数据去重
- 基于报告标题进行去重
- 确保全量数据不重复

#### 2.1.3 PDF内容获取
- 通过 Playwright 点击"在线预览"按钮
- 拦截 PDF.js 查看器加载的 PDF 文件 URL
- 下载 PDF 文件并以报告名称命名
- 降级方案：使用封面图片生成 PDF 文件

### 2.2 数据展示模块

#### 2.2.1 报告列表展示
- 表格形式展示所有报告
- 列包含：复选框、封面图片、报告名称、报告链接、操作按钮
- 封面图片缩略展示（通过代理解决跨域）
- 分页控件（每页20条）

#### 2.2.2 搜索和筛选
- 报告名称搜索（300ms 防抖）
- 标签筛选功能

### 2.3 下载功能模块

#### 2.3.1 单个下载
- 点击报告行的"下载"按钮
- 下载该报告的 PDF 文件
- 文件名为报告标题

#### 2.3.2 批量下载
- 勾选多条报告
- 点击"批量下载"按钮
- 将所选报告打包为 ZIP 文件下载

#### 2.3.3 全量下载
- 点击"全量下载"按钮
- 将所有报告打包为 ZIP 文件下载

### 2.4 启动模块

#### 2.4.1 一键启动
- 双击 .bat 文件启动
- 自动检查 Python 环境
- 自动安装依赖包
- 启动 Flask 服务器
- 自动打开浏览器访问前端页面

### 3.2 技术栈
- **后端**: Python 3 + Flask
- **爬虫**: Playwright + BeautifulSoup
- **图片处理**: Pillow
- **前端**: HTML5 + CSS3 + JavaScript (原生)
- **PDF处理**: Playwright PDF拦截 + Pillow PDF生成

### 3.3 API 设计

| 端点 | 方法 | 说明 |
|------|------|------|
| `/api/reports` | GET | 获取全量报告列表 |
| `/api/refresh` | GET | 刷新数据 |
| `/api/download-pdf/<id>` | GET | 下载单个报告PDF |
| `/api/download-batch` | POST | 批量下载ZIP |
| `/api/proxy-image` | GET | 图片代理（解决跨域） |

## 4. 非功能需求

### 4.1 性能要求
- 首次加载时间 < 5秒
- 单个报告下载 < 10秒
- 批量下载支持并发处理

### 4.2 可靠性要求
- 三层爬取策略确保数据获取成功率 > 95%
- 数据去重确保无重复
- 缓存机制减少重复请求

### 4.3 兼容性要求
- 支持 Chrome、Firefox、Edge 等主流浏览器
- 支持 Windows 操作系统
- Python 3.8+

## 6. 风险与应对

### 6.1 反爬风险
- **风险**: 目标网站有反爬保护，API直接请求返回错误
- **应对**: 使用 Playwright 浏览器环境访问，模拟真实用户行为

### 6.2 数据变化风险
- **风险**: 网站结构或API可能变化
- **应对**: 三层爬取策略提供降级方案

### 6.3 PDF获取风险
- **风险**: PDF文件URL可能无法直接获取
- **应对**: 提供降级方案（封面图片生成PDF）
