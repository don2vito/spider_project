# 克劳锐数据报告爬虫系统 - UI方案文档

## 1. 设计概述

### 1.1 设计目标
- 简洁直观的界面设计
- 高效的数据浏览体验
- 便捷的下载操作流程
- 响应式布局适配

### 1.2 设计风格
- 现代扁平化设计
- 渐变色彩主题（紫色系，呼应克劳锐品牌）
- 卡片式布局
- 清晰的视觉层次

## 4. 交互设计

### 4.1 页面加载流程
```
用户打开页面
    ↓
显示加载动画
    ↓
请求 /api/reports
    ↓
数据返回
    ↓
渲染表格
    ↓
隐藏加载动画
```

### 4.2 搜索流程
```
用户输入搜索词
    ↓
300ms 防抖
    ↓
前端过滤数据
    ↓
重新渲染表格
    ↓
更新分页
```

### 4.3 单个下载流程
```
用户点击"下载"按钮
    ↓
显示加载提示
    ↓
请求 /api/download-pdf/{id}
    ↓
浏览器下载 PDF 文件
    ↓
显示成功提示
```

### 4.4 批量下载流程
```
用户勾选报告
    ↓
点击"批量下载"按钮
    ↓
显示确认对话框
    ↓
用户确认
    ↓
显示加载提示
    ↓
请求 /api/download-batch
    ↓
浏览器下载 ZIP 文件
    ↓
显示成功提示
```

### 4.5 全量下载流程
```
用户点击"全量下载"按钮
    ↓
显示确认对话框
    ↓
用户确认
    ↓
显示加载提示（含进度）
    ↓
请求 /api/download-batch (all=true)
    ↓
浏览器下载 ZIP 文件
    ↓
显示成功提示
```

## 10. 无障碍设计

### 10.1 键盘导航
- Tab 键切换焦点
- Enter 键确认操作
- Esc 键关闭弹窗

### 10.2 屏幕阅读器
- 图片添加 alt 属性
- 按钮添加 aria-label
- 表格添加 aria-label

### 10.3 色彩对比
- 文字与背景对比度 ≥ 4.5:1
- 重要信息不仅依赖颜色区分
