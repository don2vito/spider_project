# 电子教材下载工具 - 产品需求文档 (PRD)

## 1. 产品概述

### 1.1 产品名称
电子教材下载工具（Electronic Textbook Downloader）

### 1.2 产品定位
一款面向教育工作者、家长及学生的桌面端工具，用于从国家中小学智慧教育平台（`https://basic.smartedu.cn/tchMaterial`）批量获取、筛选和下载电子教材PDF文件。

### 1.3 目标用户
| 用户类型 | 使用场景 |
|---------|---------|
| 教师 | 批量下载所需学科教材用于备课 |
| 家长 | 为孩子下载对应年级的电子教材 |
| 学生 | 自主获取学习资料 |
| 教研人员 | 收集全量教材数据进行教学研究 |

### 1.4 核心价值
- **全量数据**：一次性获取平台全部 3600+ 条教材数据
- **智能筛选**：5维度多选筛选，快速定位目标教材
- **一键下载**：支持单个和批量PDF下载，无需逐页手动操作
- **零门槛**：双击 `.bat` 即可启动，无需配置环境

---

## 2. 背景与问题

### 2.1 现状分析
国家中小学智慧教育平台提供了丰富的电子教材资源，但存在以下痛点：
1. **数据分散**：教材分布在6个学段 × 37个学科 × 124个版本 × 21个年级 × 186个册别中
2. **无法批量操作**：原平台仅支持在线浏览，缺少批量下载功能
3. **筛选效率低**：需逐级点击筛选，无法同时选择多个条件
4. **PDF获取困难**：教材以在线阅读器形式呈现，无直接下载入口

### 2.2 技术发现
通过逆向分析平台前端代码，发现以下技术特征：
- 所有教材数据通过4个静态JSON文件预加载到前端（`part_100.json` ~ `part_103.json`）
- 筛选逻辑完全在前端执行，无需登录认证
- PDF文件存储在CDN上，可通过详情API获取真实下载地址
- 公共CDN（`c1.ykt.cbern.com.cn`）可直接访问PDF文件

## 4. 非功能需求

### 4.1 性能要求
| 指标 | 要求 |
|------|------|
| 数据加载时间 | ≤ 15秒（4个分片并行下载） |
| 筛选响应时间 | ≤ 500ms（内存中过滤） |
| PDF下载启动 | ≤ 5秒（含详情API请求） |
| 页面首次渲染 | ≤ 3秒 |

### 4.2 兼容性要求
| 环境 | 要求 |
|------|------|
| 操作系统 | Windows 7/10/11 |
| Python | 3.8+ |
| 浏览器 | Chrome 80+、Edge 80+、Firefox 75+ |
| 网络环境 | 需能访问 `*.ykt.cbern.com.cn` 域名 |

### 4.3 数据规模
| 维度 | 数量 |
|------|------|
| 教材总数 | ~3600+ 条 |
| 学段 | 6 个 |
| 学科 | 37 个 |
| 版本 | 124 个 |
| 年级 | 21 个 |
| 册别 | 186 个 |
| 单个PDF大小 | 10MB ~ 200MB |

### 4.4 安全与合规
- 不存储用户个人信息
- 不绕过平台认证机制（仅访问公开数据）
- 下载的教材仅供个人学习使用

## 5. 技术架构

### 5.1 系统架构

```
┌──────────────┐       ┌──────────────┐       ┌──────────────────┐
│   Browser     │──────▶│  Flask Server │──────▶│  SmartEdu CDN    │
│  (index.html) │ HTTP  │  (server.py)  │ HTTPS │  (JSON + PDF)    │
└──────────────┘       └──────────────┘       └──────────────────┘
                              │
                    ┌─────────┴─────────┐
                    │   Memory Cache     │
                    │  - textbooks[]     │
                    │  - filters{}       │
                    │  - pdf_url_cache{} │
                    └───────────────────┘
```

### 5.2 技术选型

| 层级 | 技术 | 选型理由 |
|------|------|---------|
| 后端框架 | Flask | 轻量、易部署、Windows兼容性好 |
| HTTP客户端 | requests | 成熟稳定、支持流式下载 |
| 前端 | 原生HTML/CSS/JS | 零构建、零依赖、便于分发 |
| 并发 | threading | 4个分片并行下载 |
| 数据格式 | JSON | 与数据源格式一致 |

### 5.3 API设计

| 方法 | 路径 | 功能 | 参数 |
|------|------|------|------|
| GET | `/` | 返回前端页面 | 无 |
| GET | `/api/filters` | 获取筛选维度及选项 | 无 |
| GET | `/api/textbooks` | 获取筛选后的教材列表 | `xd`,`xk`,`bb`,`nj`,`cc` |
| GET | `/api/pdf-url/<id>` | 获取PDF下载URL | path参数 |
| GET | `/api/download/<id>` | 代理下载PDF文件 | path参数 |

### 5.4 数据流

```
1. 启动 → 请求版本文件 → 获取4个分片URL
2. 并行请求4个分片JSON → 合并 → 提取筛选选项 → 缓存
3. 浏览器加载 → 请求筛选选项 → 渲染下拉菜单
4. 用户选择筛选 → 请求教材列表 → 内存过滤 → 返回结果
5. 用户点击下载 → 请求详情API → 提取PDF URL → 代理下载
```

## 9. 已知限制与风险

| 编号 | 限制/风险 | 影响 | 缓解措施 |
|------|----------|------|---------|
| LR-01 | PDF CDN地址可能随平台更新而变化 | 下载失败 | 从版本文件动态获取分片URL |
| LR-02 | 批量下载时浏览器可能阻止多次下载 | 部分文件未下载 | 间隔800ms + 用户手动允许 |
| LR-03 | Flask开发服务器不适合高并发 | 多用户同时使用时性能下降 | 当前为单用户桌面工具，可接受 |
| LR-04 | 数据仅在启动时加载一次 | 运行期间新增教材不可见 | 重启服务器刷新数据 |
| LR-05 | 无断点续传能力 | 大文件中断后需重新下载 | 流式传输减少中断概率 |
