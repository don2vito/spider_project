# 电子教材下载工具 - UI设计方案

## 1. 设计概述

### 1.1 设计目标
为电子教材下载工具打造一个**简洁、高效、专业**的桌面端Web界面，让用户能够快速筛选和下载所需教材。

### 1.2 设计原则
- **信息密度优先**：3600+条数据需要高效展示，表格为核心交互
- **操作路径最短**：筛选→定位→下载，三步完成
- **状态即时反馈**：加载、筛选、下载每个操作都有明确的视觉反馈
- **零学习成本**：界面元素语义清晰，无需说明文档

### 1.3 设计风格
- **风格定位**：现代简约 / 工具型应用
- **视觉调性**：专业、克制、高效
- **参考对象**：教育类SaaS平台后台管理界面

## 5. 交互流程

### 5.1 页面加载流程

```
打开页面
   │
   ▼
显示加载遮罩 ("正在加载筛选选项...")
   │
   ▼
GET /api/filters → 获取筛选维度和选项
   │
   ▼
渲染5个多选下拉筛选器
   │
   ▼
隐藏加载遮罩
   │
   ▼
GET /api/textbooks (无筛选参数) → 获取全部教材
   │
   ▼
渲染表格 (3637条, 按标题升序排列)
```

### 5.2 筛选交互流程

```
用户点击筛选器触发器
   │
   ▼
展开下拉菜单 (其他已展开的自动关闭)
   │
   ▼
用户勾选/取消选项
   │
   ├── 更新触发器显示文本 (已选数量)
   ├── 更新"全选"checkbox状态
   │
   ▼
自动发送 GET /api/textbooks?xd=...&xk=...
   │
   ▼
重新渲染表格
   │
   ├── 有结果 → 显示表格
   └── 无结果 → 显示空状态
```

### 5.3 单个下载流程

```
用户点击 [⬇ 下载] 按钮
   │
   ▼
按钮变为 loading 状态 ("⏳ 获取中...")
   │
   ▼
GET /api/download/<contentId>
   │
   ├── 服务端: 查PDF URL缓存
   │     ├── 命中 → 直接使用
   │     └── 未命中 → 请求详情API → 提取PDF URL → 缓存
   │
   ▼
服务端流式代理下载PDF
   │
   ├── 成功 → 浏览器保存文件 → 按钮变为 done ("✓ 完成")
   └── 失败 → 按钮变为 error ("✕ 重试") → 可点击重试
```

### 5.4 批量下载流程

```
用户点击 [⬇ 下载全部] 按钮
   │
   ▼
按钮禁用 ("⏳ 下载中...")
显示进度条 ("正在下载 0/N...")
   │
   ▼
循环遍历当前筛选结果:
   │
   ├── 更新进度 (completed/total)
   ├── 下载当前文件 (同单个下载流程)
   ├── 更新对应行按钮状态
   ├── 等待 800ms
   │
   ▼
全部完成
   │
   ▼
进度条显示总结 ("下载完成！共 N 条，成功 X，失败 Y")
按钮恢复可用
5秒后自动隐藏进度条
```

## 6. 响应式设计

### 6.1 断点规则

| 断点 | 宽度 | 适配策略 |
|------|------|---------|
| 桌面端 | > 768px | 完整布局 |
| 移动端 | ≤ 768px | 紧凑布局 |

### 6.2 移动端适配

```css
@media (max-width: 768px) {
  .header { padding: 20px 16px; }
  .header h1 { font-size: 20px; }        /* 标题缩小 */
  .container { padding: 16px 12px 40px; }
  .card { padding: 16px; }               /* 卡片内边距缩小 */
  .filter-group { min-width: 140px; }     /* 筛选器最小宽度缩小 */
  .toolbar { flex-direction: column; }    /* 工具栏纵向排列 */
}
```

### 6.3 表格横向滚动
- 表格外层容器设置 `overflow-x: auto`
- 表格列使用 `white-space: nowrap` 防止换行
- 标题列设置 `max-width: 360px` 允许截断

## 9. 无障碍设计

| 措施 | 说明 |
|------|------|
| 语义化HTML | 使用 `<table>`, `<thead>`, `<tbody>`, `<th>`, `<button>` |
| 键盘可访问 | checkbox原生支持键盘操作 |
| 颜色对比度 | 主文字 `#1e293b` 在白底上对比度 > 7:1 |
| 文字不依赖颜色 | 状态通过图标+文字双重表达（⬇/⏳/✓/✕） |
| title属性 | 长文本单元格提供title悬停提示 |
| UTF-8编码 | 文件名使用RFC 5987编码确保兼容 |

### 10.2 筛选区域

5个筛选器横向排列（自动换行），每个筛选器包含：
- 灰色小写标签（如"学段"）
- 白色触发框 + 下拉箭头
- 展开后显示checkbox列表 + 全选选项

### 10.3 数据表格

表格包含10列，固定表头，斑马纹行，hover高亮。每行末尾有蓝色下载按钮。工具栏左侧显示结果计数和排序按钮，右侧显示蓝色渐变的"下载全部"按钮。
