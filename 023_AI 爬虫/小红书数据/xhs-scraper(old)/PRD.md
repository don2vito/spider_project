## 1. 产品概述

### 1.1 产品定位

XHS Data Scraper 是一款面向内容运营、市场研究、竞品分析等场景的**本地化小红书数据采集与分析工具**。用户通过浏览器Cookie认证后，可按关键词或作者名批量采集笔记全量数据，支持一键打包下载和智能数据分析。

### 1.2 目标用户

| 用户角色 | 使用场景 |
|---------|---------|
| 内容运营 | 采集竞品笔记数据，分析热门内容趋势 |
| 市场研究 | 获取特定话题下的用户讨论和情感倾向 |
| 品牌营销 | 监控品牌相关笔记的传播效果和用户反馈 |
| 数据分析师 | 批量获取小红书数据用于深度分析 |

### 1.3 核心价值

- **全量数据采集**：标题、正文、图片、视频、评论、回复、互动数据一站获取
- **零部署成本**：双击 `start.bat` 即可启动，无需云服务
- **智能分析**：内置词云、情感分析、时间趋势、互动统计四大分析维度
- **隐私安全**：所有数据在本地处理，不上传任何第三方服务器

## 3. 功能需求

### 3.1 Cookie认证管理

**需求描述**：用户通过浏览器登录小红书后，导出Cookie字符串粘贴到工具中完成认证。

| 功能项 | 说明 |
|--------|------|
| Cookie输入 | 提供文本域，用户粘贴完整Cookie字符串 |
| Cookie验证 | 设置后自动调用 `get_self_info()` 验证有效性 |
| 状态指示 | 右上角状态灯：绿色=已连接，红色=未连接/过期 |
| Cookie更新 | 支持随时重新粘贴新Cookie替换旧值 |
| 错误提示 | Cookie过期、签名错误、IP封禁等均有明确提示 |

**API**：`POST /api/cookie`、`GET /api/cookie/status`

### 3.2 关键词搜索

**需求描述**：输入关键词，搜索标题中包含该关键词的小红书笔记。

| 功能项 | 说明 |
|--------|------|
| 关键词输入 | 文本输入框，支持回车触发搜索 |
| 分页加载 | 每页20条，支持"加载更多"获取后续页 |
| 搜索结果展示 | 封面、标题、作者、发布时间、类型、点赞/收藏/评论数 |
| 结果排序 | 支持按发布时间升序/降序、点赞数升序/降序 |
| 笔记链接 | 标题可点击跳转到小红书原文 |
| xsec_token保存 | 搜索结果自动保存安全令牌，用于后续详情/评论获取 |

**API**：`POST /api/search`

**请求参数**：
```json
{
  "keyword": "搜索关键词",
  "page": 1,
  "page_size": 20,
  "sort": "general"  // general | popularity | latest
}
```

**响应字段**：
```json
{
  "has_more": true,
  "items": [{
    "note_id": "24位十六进制ID",
    "xsec_token": "安全令牌",
    "title": "笔记标题",
    "desc": "笔记描述",
    "type": "normal | video",
    "time": 1712283505000,
    "user": {"user_id": "", "nickname": "", "avatar": ""},
    "interact_info": {"liked_count": "100", "collected_count": "50", "comment_count": "20"},
    "cover": {"url": "封面图URL"}
  }]
}
```

### 3.3 作者搜索

**需求描述**：输入作者名字，自动搜索该用户并获取其主页全部笔记。

| 功能项 | 说明 |
|--------|------|
| 用户搜索 | 按作者名搜索用户列表，自动选择第一个匹配结果 |
| 全量获取 | 通过cursor分页循环获取用户所有笔记，自动合并 |
| 进度提示 | 显示当前获取进度（第N页） |
| 结果复用 | 搜索结果与关键词搜索使用相同的表格和排序功能 |

**API**：`POST /api/search/user` → `GET /api/user/{user_id}/notes`

### 3.4 笔记详情获取

**需求描述**：获取单篇笔记的完整详情，包括正文、图片、视频URL。

| 功能项 | 说明 |
|--------|------|
| 完整正文 | 获取笔记的完整描述文本（desc字段） |
| 图片URL列表 | 提取所有图片的CDN地址（注意：30秒过期） |
| 视频URL | 提取视频的CDN地址（注意：30秒过期） |
| 标签列表 | 提取话题标签（tag_list） |
| @用户列表 | 提取被@的用户（at_user_list） |
| 即时提取 | 获取详情后立即提取媒体URL，避免过期 |

**API**：`GET /api/note/{note_id}?xsec_token=xxx`

### 3.5 评论获取

**需求描述**：获取笔记的评论和二级回复。

| 功能项 | 说明 |
|--------|------|
| 一级评论 | 获取笔记下的所有评论，含作者、内容、时间、IP归属地、点赞数 |
| 二级回复 | 获取每条评论下的子评论（回复） |
| 分页支持 | 支持cursor分页获取全部评论 |
| 评论字段 | 评论ID、内容、作者信息、发布时间、IP归属地、点赞数、子评论数 |

**API**：`GET /api/note/{note_id}/comments`、`GET /api/note/{note_id}/sub_comments`

### 3.6 单篇笔记下载

**需求描述**：将单篇笔记的所有数据打包为ZIP文件下载。

| 功能项 | 说明 |
|--------|------|
| ZIP打包 | 将笔记数据打包为 `{标题}.zip` |
| 包含内容 | 元数据JSON + 正文TXT + 图片文件夹 + 视频文件 + 评论JSON/TXT |
| 元数据字段 | note_id、标题、类型、作者、发布时间、互动数据、标签、原文链接 |
| 媒体下载 | 后端即时下载图片和视频（URL 30秒过期） |
| 下载重试 | 图片下载失败自动重试3次 |

**ZIP内部结构**：
```
笔记标题/
├── note_info.json      # 结构化元数据
├── content.txt         # 完整正文
├── images/
│   ├── image_1.jpg
│   ├── image_2.jpg
│   └── ...
├── video.mp4           # 视频笔记时存在
├── comments.json       # 评论结构化数据
└── comments.txt        # 评论可读文本
```

**API**：`POST /api/download/note/{note_id}`

### 3.7 批量下载

**需求描述**：将搜索结果中的全部笔记批量打包下载。

| 功能项 | 说明 |
|--------|------|
| 批量打包 | 所有笔记各自打包为独立ZIP，再合并为一个大ZIP |
| 速率控制 | 每篇笔记之间间隔2秒，避免触发反爬 |
| 错误隔离 | 单篇失败不影响其他笔记，失败笔记记录错误信息 |
| 文件命名 | `xhs_batch_{timestamp}.zip` |
| 确认提示 | 下载前弹出确认对话框 |

**API**：`POST /api/download/batch`

### 3.8 数据分析

**需求描述**：对搜索结果进行多维度数据分析。

#### 3.8.1 基础统计

| 指标 | 说明 |
|------|------|
| 总笔记数 | 搜索结果中的笔记总数 |
| 总点赞/收藏/评论数 | 所有笔记的互动数据求和 |
| 平均点赞/收藏数 | 总数 / 笔记数 |

#### 3.8.2 互动分析

| 图表 | 说明 |
|------|------|
| TOP10笔记互动柱状图 | 横轴为笔记标题，纵轴为点赞/收藏/评论数，分组柱状图 |
| 情感分布饼图 | 正面/中性/负面占比的环形图 |

#### 3.8.3 词云与关键词

| 功能 | 说明 |
|------|------|
| 词云可视化 | wordcloud2.js渲染的彩色词云 |
| TOP20关键词列表 | 按词频排序的关键词列表，显示词频次数 |

#### 3.8.4 时间趋势

| 图表 | 说明 |
|------|------|
| 双轴折线图 | 左轴=月度笔记数量，右轴=月度点赞总数 |

**分析流程**：
1. 逐篇获取笔记详情（间隔2.5秒）
2. 调用后端分析接口（jieba分词 + snownlp情感分析）
3. 弹出模态框展示四个Tab页的分析结果

**API**：`POST /api/analyze`

## 4. 反反爬策略

### 4.1 签名绕过

| 策略 | 实现 |
|------|------|
| Playwright真实浏览器签名 | 在Chromium中执行 `window._webmsxyw()` 获取真实X-s/X-t签名 |
| stealth.min.js反检测 | 绕过Canvas/WebGL/字体等浏览器指纹检测 |
| navigator.webdriver伪装 | 设置为false，避免被识别为自动化工具 |
| 签名服务独立进程 | 签名服务与主服务解耦，互不影响 |

### 4.2 请求控制

| 策略 | 参数 |
|------|------|
| API请求最小间隔 | 2秒（中间件强制执行） |
| 下载间隔 | 图片0.3秒，批量笔记间2秒 |
| 分析详情获取间隔 | 2.5秒/篇 |
| 签名重试 | 最多3次，间隔1秒 |

### 4.3 错误处理

| 错误类型 | HTTP状态码 | 处理方式 |
|---------|-----------|---------|
| IP封禁 (IPBlockError) | 429 | 提示"IP被限制，请等待几分钟" |
| 需要验证码 (NeedVerifyError) | 403 | 提示"需要验证码，请更新Cookie" |
| 签名错误 (SignError) | 401 | 提示"Cookie可能已过期" |
| 数据获取错误 | 500 | 显示具体错误信息 |

## 5. 非功能需求

### 5.1 性能

| 指标 | 目标 |
|------|------|
| 搜索响应时间 | 单页搜索 < 5秒 |
| 单篇下载时间 | < 30秒（含媒体下载） |
| 批量下载 | 每篇约5-10秒（受速率限制影响） |
| 数据分析 | 20篇笔记约60-90秒 |

### 5.2 兼容性

| 环境 | 要求 |
|------|------|
| 操作系统 | Windows 10/11 |
| Python | 3.8+ |
| 浏览器 | Chrome 90+、Edge 90+、Firefox 90+ |
| 屏幕分辨率 | 最低1280×720，推荐1920×1080 |

### 5.3 安全性

| 措施 | 说明 |
|------|------|
| 本地运行 | 所有数据在本地处理，不上传第三方 |
| Cookie不持久化 | Cookie仅存储在内存中，重启服务需重新设置 |
| 无硬编码密钥 | 不包含任何API Key或密钥 |
| CORS配置 | 仅允许本地访问 |

## 6. 使用流程

```
1. 双击 start.bat 启动服务
2. 浏览器自动打开 http://localhost:8000
3. 在浏览器中登录 xiaohongshu.com
4. 使用Cookie导出工具获取完整Cookie字符串
5. 粘贴Cookie到页面输入框 → 点击"设置Cookie"
6. 输入关键词或作者名 → 点击搜索
7. 查看搜索结果，可排序、下载单篇或全部
8. 点击"数据分析"查看多维度分析报告
```

## 7. 已知限制

| 限制 | 说明 | 影响 |
|------|------|------|
| Cookie有效期 | 小红书Cookie约数小时至数天过期 | 需定期重新获取 |
| 媒体URL过期 | 图片/视频URL约30秒有效 | 必须后端即时下载 |
| 签名算法变更 | 小红书季度级更新签名算法 | 可能需要更新xhs库或stealth.min.js |
| IP封禁风险 | 短时间大量请求可能触发IP封禁 | 已内置速率控制 |
| 搜索结果上限 | 小红书API最多返回约100页结果 | 关键词搜索约2000条上限 |
| 情感分析精度 | snownlp基于通用模型，非小红书专用 | 分析结果仅供参考 |
