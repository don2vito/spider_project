> 版本：v1.0.0
> 更新日期：2026-05-01

---

## 1. 设计理念

### 1.1 设计方向

**"暗夜数据工坊"** — 深色主题 + 数据工具感 + 小红书品牌色点缀。

整体风格定位为**专业数据工具**而非社交应用，采用深色背景减少视觉疲劳，以小红书品牌红 `#FF2442` 作为视觉锚点，搭配多彩辅助色系区分不同数据维度。

### 1.2 设计原则

| 原则 | 说明 |
|------|------|
| 信息密度优先 | 工具类产品，一屏展示尽可能多的数据 |
| 色彩语义化 | 红色=点赞、黄色=收藏、青色=评论、绿色=成功 |
| 层次分明 | 通过背景色深浅区分区域层级 |
| 微交互反馈 | 按钮、输入框、状态切换均有动画过渡 |
| 响应式适配 | 支持桌面端和移动端基本可用 |

## 6. 背景氛围设计

### 6.1 渐变背景

页面底层使用三层径向渐变叠加，营造深邃的数据空间感：

```css
background:
  radial-gradient(ellipse at 20% 20%, rgba(255,36,66,0.06) 0%, transparent 50%),
  radial-gradient(ellipse at 80% 80%, rgba(76,123,244,0.04) 0%, transparent 50%),
  radial-gradient(ellipse at 50% 50%, rgba(168,85,247,0.03) 0%, transparent 60%);
```

- 左上角：微弱红色光晕（呼应品牌色）
- 右下角：微弱蓝色光晕
- 中心：微弱紫色光晕

### 6.2 动态漂移

背景渐变层以30秒周期缓慢漂移（translate + rotate），增加页面的"活"感，但不分散注意力。

### 6.3 自定义滚动条

6px宽度，深色轨道，浅灰色滑块，与整体暗色主题协调。

## 8. 前端技术实现

### 8.1 CDN依赖

| 库 | 版本 | 用途 |
|----|------|------|
| Chart.js | 4.4.0 | 柱状图、饼图、折线图 |
| wordcloud2.js | 1.1.2 | 词云Canvas渲染 |
| FileSaver.js | 2.0.5 | 浏览器端文件保存 |
| Noto Sans SC | Google Fonts | 中文UI字体 |
| Space Grotesk | Google Fonts | 品牌/数据字体 |

### 8.2 纯原生实现

- 无任何前端框架（React/Vue/Angular）
- 无构建工具（Webpack/Vite）
- 无CSS预处理器（Sass/Less）
- 所有样式内联在 `<style>` 标签中
- 所有逻辑内联在 `<script>` 标签中
- 通过CSS变量实现主题一致性

### 8.3 关键交互函数

| 函数 | 功能 |
|------|------|
| `setCookie()` | 设置Cookie并验证连接状态 |
| `searchByKeyword(page)` | 关键词搜索，支持分页 |
| `searchByAuthor()` | 作者搜索，自动获取全部笔记 |
| `renderTable()` | 渲染排序后的结果表格 |
| `sortResults()` | 切换排序方式并重新渲染 |
