# 小红书数据采集系统 — UI 设计方案

> **版本**: v1.0.0
> **日期**: 2026-05-02
> **设计系统**: 小红书品牌视觉体系

---

## 1. 设计理念

### 1.1 设计方向

**「数据工具的品牌化体验」** — 以小红书标志性的红色品牌色为核心视觉锚点，打造既专业又亲切的数据采集工具界面。设计追求**清晰的信息层级**和**高效的操作流程**，让用户在熟悉的品牌语境中完成复杂的数据操作。

### 1.2 设计原则

| 原则 | 说明 |
|------|------|
| 品牌一致性 | 严格遵循小红书品牌色（#FF2442）和设计语言 |
| 信息清晰 | 数据表格为主，信息密度适中，避免视觉噪音 |
| 操作高效 | 核心操作（搜索/下载/分析）一步到位 |
| 反馈即时 | 所有操作均有 Toast 通知和加载状态反馈 |
| 响应式 | 适配桌面和平板屏幕尺寸 |

## 5. 交互设计

### 5.2 Toast 通知

```
┌──────────────────────┐
│  ✓ 操作成功           │  ← 绿色 #52c41a
└──────────────────────┘

┌──────────────────────┐
│  ✕ 操作失败: 原因     │  ← 红色 #FF2442
└──────────────────────┘

┌──────────────────────┐
│  ℹ 提示信息           │  ← 蓝色 #1890ff
└──────────────────────┘
```

- **位置**: 页面顶部居中，多个 Toast 垂直堆叠
- **动画**: 从上方滑入（0.3s），3 秒后滑出消失
- **最大宽度**: 400px

### 5.3 按钮交互状态

| 状态 | 视觉变化 |
|------|---------|
| 默认 | 正常样式 |

| 按下 | 回到原位 |
| 禁用 | 透明度 0.5，cursor: not-allowed |
| 加载中 | 文字替换为 Spinner 或 "处理中..." |

## 7. 动效规范

### 7.1 过渡动画

| 元素 | 属性 | 时长 | 缓动函数 |
|------|------|------|---------|
| 按钮 | transform, box-shadow | 0.2s | ease |
| 输入框 | border-color, box-shadow | 0.2s | ease |
| 卡片 | box-shadow | 0.2s | ease |
| 表格行 | background | 0.15s | ease |
| Toast | transform, opacity | 0.3s | ease |
| 弹窗 | transform, opacity | 0.3s | ease |
| 进度条 | width | 0.3s | ease |
| Spinner | transform (rotate) | 0.8s | linear (无限循环) |

### 7.2 关键帧动画

```css
/* 旋转加载动画 */
@keyframes spin {
    to { transform: rotate(360deg); }
}

/* Toast 进入 */
@keyframes toastIn {
    from { opacity: 0; transform: translateY(-20px); }
    to { opacity: 1; transform: translateY(0); }
}

/* Toast 退出 */
@keyframes toastOut {
    from { opacity: 1; transform: translateY(0); }
    to { opacity: 0; transform: translateY(-20px); }
}

/* 弹窗进入 */
@keyframes modalIn {
    from { opacity: 0; transform: scale(0.95); }
    to { opacity: 1; transform: scale(1); }
}
```

## 9. 技术实现说明

### 9.1 前端技术栈

| 技术 | 用途 | 引入方式 |
|------|------|---------|
| HTML5 | 页面结构 | 单文件内嵌 |
| CSS3 | 样式（CSS 变量、Flex、Grid） | 单文件 `<style>` 内嵌 |
| Vanilla JS | 交互逻辑 | 单文件 `<script>` 内嵌 |
| sortable-tablesort | 表格排序 | CDN (`jsdelivr`) |
| ECharts 5 | 图表可视化 | CDN (`jsdelivr`) |

### 9.2 关键实现细节

- **单文件架构**: 所有 HTML/CSS/JS 内嵌在一个 `index.html` 中，由 FastAPI 静态文件服务提供
- **无构建步骤**: 无需 npm/webpack，直接浏览器打开即可
- **API 通信**: 使用原生 Fetch API，`const API = ''` 同源访问后端
- **图表实例管理**: ECharts 实例在分析报告展示时创建，监听 `resize` 事件自适应
- **数据缓存**: 搜索结果存储在 `currentNotes` JS 变量中，排序/分析直接操作内存数据
