## 一、整体风格

- **风格**：深色专业仪表盘风格（Dark Dashboard），适合数据密集型工具
- **主色调**：
  - 背景色：`#0f1117`（深蓝黑）
  - 卡片背景：`#1a1d27`（深灰蓝）
  - 主强调色：`#6366f1`（靛蓝紫）
  - 次强调色：`#22d3ee`（青色）
  - 成功色：`#10b981`（绿色）
  - 警告色：`#f59e0b`（琥珀色）
  - 错误色：`#ef4444`（红色）
  - 文字主色：`#e2e8f0`（浅灰白）
  - 文字次色：`#94a3b8`（灰色）
- **字体**：`-apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, "Noto Sans SC", sans-serif`
- **设计原则**：信息密度高、操作路径短、视觉层次清晰

## 三、组件详细设计

### 3.1 顶部导航栏

```
+================================================================+
|  [📊] 易观分析报告库          [🔍 搜索报告...]  [▶ 开始爬取]   |
+================================================================+
```

**各元素说明：**

| 元素 | 类型 | 说明 |
|------|------|------|
| Logo 图标 | SVG/Emoji | 📊 数据图表图标 |
| 标题文字 | 文本 | "易观分析报告库"，字体 18px，加粗 |
| 搜索框 | Input | 占位符"搜索报告..."，支持回车搜索，实时筛选 |
| 开始爬取按钮 | Button | 主色调背景，点击后变为"爬取中..."状态 |

**搜索框交互：**
- 输入关键词后 500ms 自动触发搜索（防抖）
- 清空搜索框恢复全量显示
- 搜索范围：报告标题

### 3.2 统计卡片区域

```
+------------------+ +------------------+ +------------------+ +------------------+
|  📋 总报告数      |  ✅ 已爬取         |  🖼️ 已下载图片     |  📄 已生成 PDF    |
|                  |                    |                    |                    |
|     3,930        |     2,100          |     1,800          |     1,500          |
|  / 3,930 (100%)  |  / 3,930 (53%)    |  / 12,600 (14%)   |  / 3,930 (38%)    |
+------------------+ +------------------+ +------------------+ +------------------+
```

**设计规范：**
- 4 个卡片水平排列，等宽
- 每个卡片包含：图标 + 标题 + 大数字 + 进度说明
- 大数字使用 32px 加粗，颜色对应状态（靛蓝紫）
- 进度说明使用 12px 灰色文字
- 卡片背景 `#1a1d27`，圆角 8px，轻微阴影
- 爬取进行中时，数字实时更新（每 5 秒轮询）

### 3.3 工具栏

```

```

**列宽分配：**

| 列 | 宽度 | 说明 |
|----|------|------|
| 复选框 | 40px | 固定宽度 |
| 封面图片 | 100px | 固定宽度，图片 80x110px，`object-fit: cover` |
| 报告名称 | 自适应（flex: 1） | 最多显示 2 行，超出省略号，hover 显示完整标题 |
| 分类 | 120px | 标签样式，彩色小标签 |
| 发布日期 | 120px | YYYY-MM-DD 格式 |
| 操作 | 80px | 下载按钮 |

**封面图片：**
- 通过 `/proxy/image?url=xxx` 代理加载（解决跨域）
- 加载中显示骨架屏动画（shimmer effect）
- 加载失败显示默认占位图
- 图片比例约 3:4（报告封面常见比例）

**报告名称：**
- 字体 14px，颜色 `#e2e8f0`
- 超过 2 行显示省略号（`text-overflow: ellipsis`）
- hover 时显示完整标题（tooltip）
- 点击跳转到易观分析原始页面（`target="_blank"`）
- 链接颜色 `#6366f1`，hover 下划线

**分类标签：**
- 不同分类使用不同颜色的小标签（pill 样式）
- 预设颜色映射：
  - 焦点专题分析 → `#6366f1`（靛蓝紫）
  - 行业监测分析 → `#22d3ee`（青色）
  - 趋势预测分析 → `#10b981`（绿色）
  - 其他 → `#94a3b8`（灰色）

**操作按钮：**
- 下载图标按钮（↓），hover 时显示 tooltip "下载 PDF"
- 点击触发单篇下载
- 下载中显示 loading 旋转图标

- 切换页码时自动滚动到表格顶部

## 四、交互设计

### 4.1 核心交互流程表

| 用户操作 | 界面反应 | 说明 |
|---------|---------|------|
| 页面加载 | 显示统计卡片 + 空表格或已缓存数据 | 自动从后端加载已爬取数据 |
| 输入搜索关键词 | 表格实时过滤（500ms 防抖） | 仅搜索报告标题 |
| 选择分类筛选 | 表格实时过滤 | 与搜索关键词联合过滤 |
| 点击报告名称 | 新标签页打开原文 | `target="_blank"` |
| 点击下载按钮 | 按钮变为 loading 状态 → 触发下载 | 单篇 PDF 下载 |
| 勾选复选框 | 批量下载按钮变为可用 | 支持全选/取消全选 |
| 点击批量下载 | 生成 ZIP → 触发下载 | 仅下载选中的报告 |
| 点击全量下载 | 弹出确认对话框 → 确认后显示进度 | 后台异步生成 |
| 点击开始爬取 | 弹出爬取控制面板 | 可配置爬取参数 |
| 爬取进行中 | 统计数字实时更新 | 每 5 秒轮询一次 |
| 翻页 | 表格内容更新 + 滚动到顶部 | URL 参数同步 |

### 4.2 状态设计

**按钮状态：**

| 按钮 | 默认 | Hover | 禁用 | 加载中 |
|------|------|-------|------|--------|
| 开始爬取 | 靛蓝紫背景 | 加深 | 灰色 | 显示 spinner + "爬取中..." |
| 批量下载 | 灰色（无选中时） | 靛蓝紫 | - | 显示 spinner |
| 全量下载 | 琥珀色背景 | 加深 | - | 显示 spinner |
| 单篇下载 | 透明 + 图标 | 靛蓝紫背景 | - | spinner 图标 |

**表格行状态：**

| 状态 | 表现 |
|------|------|
| 正常 | 白色背景 |
| Hover | 浅灰蓝背景 `#252836` |
| 选中 | 靛蓝紫浅色背景 `rgba(99,102,241,0.1)` |
| 下载中 | 行右侧显示进度条 |

### 4.3 加载状态

- **首次加载**：表格区域显示骨架屏动画（shimmer effect）
- **翻页加载**：表格淡入动画（fade-in, 200ms）
- **图片加载**：封面图片显示灰色占位 + shimmer，加载完成后淡入
- **图片加载失败**：显示默认占位图（📄 图标 + "暂无封面"）

### 4.4 空状态

- **无数据**：表格区域显示空状态插画 + "暂无数据，请先开始爬取" + 「开始爬取」按钮
- **搜索无结果**：显示 "未找到匹配的报告" + 清除搜索按钮

### 4.5 错误状态

- **网络错误**：表格区域显示错误提示 + 重试按钮
- **下载失败**：Toast 通知 "下载失败：{原因}" + 重试按钮
- **爬取错误**：爬取面板中显示错误计数，日志区域显示详细错误信息

## 九、技术实现说明

### 9.1 前端技术

- **纯原生实现**：HTML + CSS + JavaScript，无框架依赖
- **CSS**：使用 CSS 变量管理主题色，Flexbox/Grid 布局
- **JavaScript**：使用 Fetch API 与后端通信，async/await 异步处理
- **图标**：使用 Unicode Emoji 或内联 SVG
- **无外部依赖**：不引入任何 CSS 框架或 JS 库

### 9.2 数据流

```
前端页面加载
  → fetch('/api/crawl/status') 获取统计信息
  → fetch('/api/articles?page=1') 获取报告列表
  → 渲染表格

用户搜索/筛选
  → fetch('/api/articles?keyword=xxx&classify=xxx')
  → 重新渲染表格

用户下载
  → window.location.href = '/api/download/{id}'  (单篇)
  → fetch('/api/download/batch', POST) → blob → download  (批量)

爬取进度
  → setInterval(() => fetch('/api/crawl/status'), 5000)
  → 更新统计卡片数字
```

### 9.3 性能优化

- 图片懒加载：使用 `loading="lazy"` 属性
- 表格虚拟滚动：数据量大时考虑虚拟滚动（可选）
- 请求防抖：搜索输入 500ms 防抖
- 缓存策略：浏览器缓存静态资源
