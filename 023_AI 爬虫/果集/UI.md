# 果集数据报告爬虫系统 - UI设计方案

## 1. 设计概述

### 1.1 设计目标
- 简洁直观的界面
- 高效的数据浏览体验
- 便捷的下载操作
- 响应式布局适配

### 1.2 设计原则
- **简洁优先**：界面元素精简，突出核心功能
- **操作便捷**：常用功能一键可达
- **信息清晰**：数据展示层次分明
- **视觉统一**：配色和组件风格一致

## 5. 交互设计

### 5.1 页面加载流程
```
1. 显示加载动画
2. 请求 /api/reports 接口
3. 数据返回后隐藏加载动画
4. 渲染表格数据
5. 显示分页控件
```

### 5.2 搜索交互
```
1. 用户输入关键词
2. 300ms防抖
3. 过滤本地数据
4. 重新渲染表格
5. 重置到第一页
```

### 5.3 选择交互
```
单选：点击复选框切换选中状态
全选（当页）：点击表头复选框
全选（全部）：点击"全选"按钮
取消选择：再次点击"全选"按钮
```

### 5.4 下载交互

#### 单个下载
```
1. 点击"下载"按钮
2. 显示Toast提示"正在生成PDF"
3. 请求 /api/download-pdf/{id}
4. 浏览器触发下载
5. 显示Toast提示"下载成功"
```

#### 批量下载
```
1. 选择多条报告
2. 点击"批量下载"按钮
3. 弹出确认对话框
4. 确认后显示Toast提示
5. 请求 /api/download-batch
6. 浏览器触发ZIP下载
```

#### 全量下载
```
1. 点击"全量下载"按钮
2. 弹出确认对话框（提示数量和时间）
3. 确认后显示Toast提示
4. 请求 /api/download-batch（全部ID）
5. 浏览器触发ZIP下载
```

### 5.5 刷新交互
```
1. 点击"刷新数据"按钮
2. 按钮变为禁用状态，文字变为"刷新中..."
3. 显示进度条
4. 请求 /api/refresh
5. 数据返回后更新表格
6. 恢复按钮状态
7. 显示Toast提示
```

## 13. 性能优化

### 13.1 图片优化
- 封面图片懒加载
- 图片代理缓存
- 错误图片占位符

### 13.2 数据优化
- 本地数据过滤（搜索）
- 分页减少DOM节点
- 防抖减少请求

### 13.3 渲染优化
- 虚拟滚动（大数据量）
- requestAnimationFrame
- 减少重排重绘
