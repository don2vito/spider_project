# 炼丹炉行业报告爬虫系统 - 产品需求文档 (PRD)

## 1. 项目概述

### 1.1 项目背景
针对炼丹炉（huo1818.com）行业报告页面，开发一套完整的数据采集与管理系统，实现报告数据的自动化抓取、展示和下载功能。

### 1.2 目标网站分析
- **目标URL**: `https://www.huo1818.com/report/{page}?offset={offset}`
- **技术架构**: Next.js 服务端渲染 (SSR)
- **数据格式**: JSON 数据嵌入在 HTML 的 `<script>` 标签中
- **反爬措施**: 无明显反爬机制，数据直接渲染在页面中

### 1.3 核心数据字段
| 字段名 | 说明 | 示例 |
|--------|------|------|
| reportId | 报告唯一标识 | HYBG20260305000 |
| title | 报告标题 | 健康饮料市场消费趋势洞察 |
| coverUrl | 封面图片URL | https://static-file-cdn.huo1818.com/banner/xxx.png |
| pdfUrl | PDF下载链接 | https://static-file-cdn.huo1818.com/banner/xxx.pdf |
| publishTime | 发布时间 | 2026-03-05 16:52:38 |
| viewCount | 浏览次数 | 732 |

## 2. 功能需求

### 2.1 三层爬虫架构

#### 第一层：API接口探测（优先级：高）
- **目标**: 寻找后端 JSON API 接口
- **实现**: 通过分析网络请求，尝试直接调用数据接口
- **备用**: 如找到API，直接提取关键字段

#### 第二层：HTML解析（优先级：高）
- **目标**: 解析服务端渲染的 HTML 页面
- **实现**: 提取 `<script>` 标签中的 JSON 数据
- **技术**: Python + BeautifulSoup/正则表达式
- **数据提取路径**: `window.__NEXT_DATA__.props.pageProps.reports`

#### 第三层：Browser Use兜底（优先级：中）
- **目标**: 当静态抓取失效时的备用方案
- **实现**: Playwright 控制真实浏览器
- **场景**: 网站改版、JavaScript动态加载、反爬升级

### 2.2 数据采集功能

#### 2.2.1 全量数据抓取
- 自动遍历所有分页（当前共8页）
- 去重机制：基于 reportId 进行数据去重
- 增量更新：支持只抓取新数据

#### 2.2.2 数据存储
- 本地 JSON 文件存储
- 数据结构：
```json
{
  "reports": [
    {
      "reportId": "HYBG20260305000",
      "title": "健康饮料市场消费趋势洞察",
      "coverUrl": "https://...",
      "pdfUrl": "https://...",
      "publishTime": "2026-03-05 16:52:38",
      "viewCount": 732,
      "detailUrl": "https://www.huo1818.com/report/1"
    }
  ],
  "lastUpdate": "2026-05-26T10:00:00",
  "totalCount": 64
}
```

### 2.3 Web 应用功能

#### 2.3.1 数据展示
- **表格视图**: 展示封面图片、报告名称、报告链接
- **卡片视图**: 网格布局展示报告封面
- **搜索功能**: 按报告标题关键词搜索
- **排序功能**: 按发布时间、浏览量排序
- **分页功能**: 前端分页，每页显示20条

#### 2.3.2 下载功能
- **单条下载**: 点击下载单个报告PDF
- **批量下载**: 勾选多个报告批量下载
- **全量下载**: 一键下载所有报告PDF
- **文件名规则**: 使用报告标题作为文件名（清理非法字符）

#### 2.3.3 数据刷新
- **手动刷新**: 点击按钮重新抓取数据
- **自动刷新**: 每次打开页面自动抓取最新数据
- **进度显示**: 显示抓取进度和状态

## 4. 详细功能规格

### 4.1 爬虫模块 (crawler.py)

#### 4.1.1 数据提取规则
```python
# HTML中的数据路径
script_tag = soup.find('script', string=re.compile('__NEXT_DATA__'))
data = json.loads(script_tag.string)
reports = data['props']['pageProps']['reports']
```

#### 4.1.2 字段映射
| 源字段 | 目标字段 | 处理 |
|--------|----------|------|
| reportId | id | 直接使用 |
| title | title | 清理空白字符 |
| coverUrl | cover_url | 直接使用 |
| pdfUrl | pdf_url | 直接使用 |
| publishTime | publish_time | 转换为ISO格式 |
| viewCount | view_count | 转为整数 |

#### 4.1.3 去重策略
- 使用 `reportId` 作为主键
- 抓取前读取已有数据，建立ID集合
- 新数据与已有数据合并，去重后保存

### 4.2 Web API 接口

| 接口 | 方法 | 说明 |
|------|------|------|
| /api/reports | GET | 获取所有报告列表 |
| /api/reports/refresh | POST | 手动刷新数据 |
| /api/download/<id> | GET | 下载单个PDF |
| /api/download/batch | POST | 批量下载PDF（返回ZIP） |
| /api/download/all | GET | 下载所有PDF（返回ZIP） |

## 5. 非功能需求

### 5.1 性能要求
- 页面加载时间 < 2秒
- 数据抓取速度 > 5页/分钟
- 支持并发下载3个PDF

### 5.2 可靠性
- 网络异常自动重试3次
- 数据完整性校验
- 断点续传支持

### 5.3 安全性
- 请求频率控制，避免被封
- User-Agent轮换
- 本地存储，不上传云端

## 6. 部署与使用

### 6.1 环境要求
- Python 3.8+
- Windows 10/11 (for .bat)
- 网络连接

### 6.2 安装步骤
```bash
pip install -r requirements.txt
playwright install chromium
```

### 6.3 启动方式
双击 `start.bat` 或运行：
```bash
python app.py
```

### 6.4 访问地址
- 本地: `http://localhost:5000`
- 自动打开浏览器

## 7. 风险与应对

| 风险 | 影响 | 应对措施 |
|------|------|----------|
| 网站改版 | 高 | 三层架构兜底，Browser Use备用 |
| IP被封 | 中 | 请求间隔、User-Agent轮换 |
| PDF链接失效 | 中 | 下载前校验，记录失败项 |
| 数据量大 | 低 | 分页加载、本地缓存 |
