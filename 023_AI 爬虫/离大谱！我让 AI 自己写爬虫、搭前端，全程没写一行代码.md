## 一、需求

在我的工作当中，每隔半年都要给股份公司写报告，用来给上市公司的半年报和年报内容提供素材。在撰写报告的时候，我也需要在往年发布过的半年报和年报中了解内容、熟悉材料。这就产生了需求，我希望能够指定一些条件，然后根据条件批量化下载报告。

根据以上需求，我第一个想到的实现路径就是爬虫方案。大约一年之前，我尝试过使用 AI 来生成爬虫代码，那还只是个最简单的静态网页，结果错误百出，惨不忍睹，那时候的 AI 根本就不会分析网页，连网页源代码都需要我手动上传，遇到反爬那更是只能干瞪眼了。

时过境迁，我想看看 AI 的进步会有多大，能不能自动分析网页并获取数据。说实话，此时的我并没有报什么期待。

下载上市公司的公告一般会到**巨潮资讯网**，地址是`https://www.cninfo.com.cn/new/commonUrl/pageOfSearch?url=disclosure/list/search`，界面见下图。可以选择时间段、代码、关键字、板块、行业、类型，筛选出结果之后，只能一篇篇点进去，单独下载 PDF 文件。像我这样有批量下载的需求，就需要上一点手段了。

## 二、过程

我自己迭代了一个目前试下来比较顺畅的提示词。

```textplain
使用“vibecoding-helper”、“frontend-design”、“docx”这几个 skill,先制定计划，等我确认计划之后（输出 markdown 格式的开发计划），再进行开发，开发完成后进行测试，测试通过后方可交付。

针对网页【网页链接】，研究一下网页源代码，注意可能会有动态 Ajax、Json 技术或者其它反爬技术，分层级进行研究可行的爬取方案（第一层，寻找并拦截后端接口。先不要去解析 HTML，请先写一段代码尝试抓包或者分析该网站的网络请（Network），重点寻找返回 JSON 格式工作信息的 API 接口，如果找到了 API，直接提取关键字段储存。第二层，大模型生成解析则。这是一个服务端渲染的 HTML 网页，请你分析这个网页的 DOM 结构，帮我写出需要提取字段的 XPath 规则或者 BeautifulSoup/正则表达式的提取代码，将这套代码封装成一个 Python 函数。第三层，Browser Use 智能兜底。如果前面的静态抓取和 API 接口都失效了，请回退到使用 Playwright/Browser Use 控制真实浏览器，通过截图和大模型视觉能力，点击对应元素来获取数据。）。循环爬取【具体爬取需求】，我需要得到全量数据（注意不要重复爬取），请使用python生成爬虫代码作为代理服务器；实现一个HTML应用。要求每次打开这个HTML应用，【具体交互需求】，自动抓取相应的的全量网页数据，展示结果表格（【具体表格呈现需求】），提供下载按钮（【具体下载文件格式和排版、字段要求】）的功能。最后，需要生成一个.bat文件，运行后直接启动代理服务器并打开前端页面（一键启动），默认这个.bat文件和python代码以及 HTML 文件处在同一个文件夹下，.bat文件中的内容使用英文。

针对以上方案，生成一份完整的 PRD 和一份完整的 UI 方案，输出为 word 格式，给我下载。
```

一般来说，第一版交付的产物是一个很好的起点，但未必能顺利跑通，或者前端界面会有些许问题，这都是正常的，一稿过那都是理想情况下才会出现的。我们要做的就是根据报错或者问题，通过截图（需要具备视觉理解能力的模型）或者文字描述的形式，将问题告诉 AI，让它来定位问题点，并修复问题。如此反复几轮，基本上就能得到满意度产品了。
