# 网易数读栏目爬虫系统 - 产品需求文档 (PRD)

## 1. 产品概述

### 1.1 产品名称
网易数读栏目爬虫系统 (NetEase Data Blog Crawler)

### 1.2 产品定位
一款面向数据分析师、研究人员和内容收藏者的网易新闻数读栏目数据抓取与下载工具，支持自动抓取、数据展示、PDF批量下载等功能。

### 1.3 目标用户
- 数据分析师：需要批量获取网易数读报告进行研究
- 内容收藏者：希望保存感兴趣的报告为PDF格式
- 学术研究者：需要引用网易数读的数据报告

### 1.4 核心价值
- **自动化**：一键抓取全量数据，无需手动复制
- **完整性**：获取报告标题、链接、封面图、内容图片
- **便捷性**：自动生成PDF，支持批量下载
- **去重性**：智能识别已下载内容，避免重复

## 2. 功能需求

### 2.1 数据抓取模块

#### 2.1.1 三层爬虫策略
| 层级 | 策略 | 优先级 | 说明 |
|------|------|--------|------|
| 第一层 | API接口尝试 | 高 | 尝试调用网易后端API获取JSON数据 |
| 第二层 | HTML解析 | 中 | 解析页面JavaScript变量提取数据 |
| 第三层 | Browser Use | 低 | 使用Playwright控制浏览器兜底 |

#### 2.1.2 抓取字段
- 报告ID（文章唯一标识）
- 报告标题
- 报告链接
- 封面图片URL
- 发布时间
- 评论数量
- 关键词标签
- 详情页所有内容图片URL列表

#### 2.1.3 数据去重
- 使用报告ID作为主键
- 本地SQLite数据库记录已抓取数据
- 每次抓取前检查数据库，跳过已存在记录

### 2.2 数据展示模块

#### 2.2.1 列表展示
- 封面图片缩略图
- 报告标题（可点击跳转原文）
- 发布时间
- 评论数
- 操作按钮（下载、预览）

#### 2.2.2 搜索筛选
- 关键词搜索（标题模糊匹配）
- 时间范围筛选
- 分类标签筛选

#### 2.2.3 数据统计
- 总报告数量
- 今日新增数量
- 已下载数量

### 2.3 PDF下载模块

#### 2.3.1 单份下载
- 点击下载按钮生成PDF
- PDF文件名使用报告标题
- PDF内容为详情页所有图片按顺序排列

#### 2.3.2 批量下载
- 支持多选报告
- 批量生成PDF并打包为ZIP
- 显示批量下载进度

#### 2.3.3 全量下载
- 一键下载所有报告
- 分批处理避免内存溢出
- 生成ZIP压缩包

### 2.4 系统功能

#### 2.4.1 自动刷新
- 页面加载时自动抓取最新数据
- 显示抓取进度
- 支持手动刷新

#### 2.4.2 数据缓存
- 前端localStorage缓存
- 后端SQLite数据库缓存
- 增量更新机制

#### 2.4.3 日志记录
- 抓取日志
- 错误日志
- 下载日志

## 3. 非功能需求

### 3.1 性能需求
- 页面加载时间 < 3秒
- 单次抓取请求超时 30秒
- 支持并发下载 5个文件
- PDF生成速度 1页/秒

### 3.2 可靠性需求
- 网络异常自动重试（3次）
- 图片下载失败跳过继续
- 数据完整性校验
- 异常日志记录

### 3.3 易用性需求
- 一键启动，无需配置
- 界面简洁直观
- 操作反馈明确
- 错误提示友好

### 3.4 安全需求
- 请求频率限制（1秒/次）
- 用户代理轮换
- 无敏感信息存储

## 5. 技术约束

### 5.1 目标网站约束
- 网易数读栏目无公开API
- 数据嵌入在JavaScript变量中
- 图片使用CDN加速
- 可能有反爬机制

### 5.2 实现约束
- 使用Python + Flask开发后端
- 使用原生HTML/CSS/JS开发前端
- 支持Windows系统一键启动
- 无需外部数据库依赖

## 6. 验收标准

### 6.1 功能验收
- [ ] 成功抓取全部报告数据
- [ ] 数据无重复、无遗漏
- [ ] 单份PDF下载正常
- [ ] 批量PDF下载正常
- [ ] 一键启动脚本正常工作

### 6.2 性能验收
- [ ] 首次抓取完成时间 < 60秒
- [ ] 单份PDF生成时间 < 10秒
- [ ] 页面响应时间 < 3秒

### 6.3 稳定性验收
- [ ] 连续运行2小时无崩溃
- [ ] 网络异常后自动恢复
- [ ] 数据缓存正常工作

## 7. 风险与应对

| 风险 | 影响 | 应对措施 |
|------|------|----------|
| 网站改版导致爬虫失效 | 高 | 设计三层降级策略，预留维护接口 |
| 反爬机制封禁IP | 中 | 限制请求频率，使用随机User-Agent |
| PDF生成内存溢出 | 中 | 分批处理，限制并发数 |
| 图片下载失败 | 低 | 失败跳过，记录日志 |
