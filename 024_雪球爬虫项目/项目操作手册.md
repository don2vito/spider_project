# 雪球爬虫项目操作手册

## 项目概述

本项目是一个用于处理雪球图书图片并生成PDF文档的工具集合。主要功能包括图片下载、处理、排序和批量转换为PDF文档，特别适用于将分章节的图片书籍合并为完整的PDF文档。

## 项目结构

```
d:/project/雪球爬虫项目/
├── image_downloader.py    # 图片下载器
├── image_processor.py     # 图片处理器
├── pdf_generator.py       # PDF生成器
├── images_to_pdf_main.py  # 主程序
├── test_batch_processing.py  # 批次处理测试程序
├── verify_pdf_pages.py    # PDF页数验证工具
├── check_pdf_integrity.py # PDF完整性检查工具
├── 雪球图书 - 进阶吧 投资者/ # 图片文件夹
└── 进阶吧 投资者（1-6册全）.pdf # 生成的PDF文件
```

## 核心功能模块

### 1. 图片下载器 (image_downloader.py)

用于从指定链接下载图片资源。

**主要功能：**
- 批量下载图片
- 支持断点续传
- 下载进度跟踪
- 错误重试机制

**使用方法：**
```python
# 示例代码
from image_downloader import ImageDownloader

downloader = ImageDownloader(save_dir="雪球图书 - 进阶吧 投资者")
image_urls = ["https://example.com/image1.jpg", "https://example.com/image2.jpg"]
downloader.download_images(image_urls)
```

### 2. 图片处理器 (image_processor.py)

负责图片的排序、验证和预处理。

**主要功能：**
- 按数字序号排序图片文件
- 验证图片文件完整性
- 获取图片尺寸信息

**关键方法：**
- `get_sorted_images()`: 获取排序后的图片文件列表
- `validate_images()`: 验证图片文件有效性

### 3. PDF生成器 (pdf_generator.py)

用于将图片转换为PDF文档。

**主要功能：**
- 单张图片转换为PDF页
- 批量图片合并为PDF
- 自定义PDF页面大小
- 支持分批次处理大型图片集合

### 4. 主程序 (images_to_pdf_main.py)

整合所有功能，提供完整的图片到PDF转换流程。

**主要功能：**
- 自动处理指定文件夹中的所有图片
- 分批次生成PDF（默认每批100张图片）
- 自动合并临时PDF文件
- 完善的错误处理和资源清理

## 使用指南

### 基本使用流程

1. **准备图片文件**
   - 将图片放入指定文件夹（默认："雪球图书 - 进阶吧 投资者"）
   - 确保图片文件按顺序命名（如1.jpg, 2.jpg, 3.jpg...）

2. **运行主程序**
   ```bash
   python images_to_pdf_main.py
   ```

3. **查看生成的PDF文件**
   - 默认输出文件："进阶吧 投资者（1-6册全）.pdf"

### 测试模式使用

对于大型任务，建议先使用测试模式验证功能：

```bash
python test_batch_processing.py
```

测试模式会：
- 只处理前50张图片
- 使用较小的批次大小（20张/批）
- 生成测试用PDF文件

## 验证工具使用

### 验证PDF页数

```bash
python verify_pdf_pages.py
```

此工具会检查生成的PDF文件页数是否与原始图片数量一致。

### 检查PDF完整性

```bash
python check_pdf_integrity.py
```

此工具会检查PDF文件的基本信息、结构完整性和页面质量。

## 常见问题与解决方案

### 问题1：图片排序不正确

**解决方案：**
- 确保图片文件使用纯数字命名（如1.jpg, 2.jpg...）
- 避免使用混合字符（如page1.jpg, img2.jpg）
- 对于三位数图片，确保前导零一致（如001.jpg, 002.jpg...）

### 问题2：内存占用过高

**解决方案：**
- 修改`images_to_pdf_main.py`中的`batch_size`参数，减小批次大小
- 确保代码中的`gc.collect()`调用正常工作以释放内存

### 问题3：PDF生成失败

**解决方案：**
- 检查图片文件是否完整且未损坏
- 确认磁盘空间充足（大型PDF需要较多磁盘空间）
- 查看错误日志，定位具体失败原因

## 性能优化建议

1. **调整批次大小**
   - 对于内存较小的系统，建议将批次大小调整为50-80
   - 对于内存较大的系统，可以增加到200-300以提高处理速度

2. **临时文件管理**
   - 确保有足够的临时磁盘空间
   - 程序会在完成后自动清理临时文件

3. **并行处理**
   - 对于大型项目，可以考虑实现多线程处理以提高效率

## 注意事项

1. **文件路径**
   - 避免在文件路径中使用特殊字符
   - 中文路径可能需要额外处理以确保兼容性

2. **图片格式**
   - 支持常见图片格式：JPG, PNG, BMP等
   - 对于非标准格式，可能需要预处理转换为标准格式

3. **资源清理**
   - 程序使用try-finally确保即使出错也能清理临时文件
   - 如果程序异常终止，可能需要手动删除生成的临时PDF文件
